## Fixed

- **Collapsed folders stay quiet.** Moving the pointer over the rows below a closed pinned folder no longer pops up
  the card of a link hidden inside it.
- **A link from a pinned tab opens as a plain tab.** The first link you open in the background from a pinned tab no
  longer gets a group of its own; the second one gathers both into a group.
- **No borrowed icons while a tab wakes up.** A tab loading through a blank page used to flash another site's
  icon (often a calendar) before its own; it now keeps its own icon.
